# 图标资源说明

当前所有图标都是 `res/drawable` 下的**占位 Vector XML**，按 24dp 视觉尺寸绘制，运行时由 Compose 统一着色（白 / 灰 / 橙色）。替换成正式图标时**不需要改任何代码**，只要保持资源名不变即可。

## 替换步骤（PNG 方案）

1. 准备白色单色、透明背景的 PNG（图标本身带颜色时会被运行时 tint 统一染色）。
2. 按密度放入对应目录（推荐直接放 `res/drawable-xxxhdpi/`，或只放一份到 `res/drawable-nodpi/`）：
   - mdpi 24px、hdpi 36px、xhdpi 48px、xxhdpi 72px、xxxhdpi 96px（以 24dp 图标为例）。
3. **先删除同名占位 XML**，例如替换「拍照」图标时：
   - 删除 `app/src/main/res/drawable/ic_nav_capture.xml`
   - 再放入 `app/src/main/res/drawable-xxxhdpi/ic_nav_capture.png`
   - 不要同时保留同名 XML 与 PNG，避免资源选择不确定或构建冲突。
4. 重新 Sync + 构建安装即可生效，资源 ID（`R.drawable.ic_nav_capture` 等）不变，无需改代码。

## 替换步骤（SVG 方案，推荐）

1. Android Studio → `File > New > Vector Asset` → `Local file (SVG, PSD)`。
2. 选择 SVG，`Name` 填上表中的资源名（如 `ic_nav_capture`），`Size` 设为 `24dp × 24dp`。
3. 覆盖生成到 `app/src/main/res/drawable/` 下的同名 XML（Vector Asset 会直接替换占位文件）。
4. 保持 `android:width` / `android:height` 为 24dp、`viewportWidth/Height` 为 24，即可与现有布局兼容。

## 着色说明

代码使用 `ColorFilter.tint(...)` 给图标统一上色：

- 底部导航：选中 `onSurface`、未选中 `onSurfaceVariant`（随深浅主题自动切换，保证对比度）
- 前后摄 / 快门：白色（忙碌时灰色）
- 删除：橙色 `#FF6B35`，禁用时灰色
- 合成进度：橙色 `#FF6B35`
- 勾选：白色
- 水印入口：白色；面板展开时橙色 `#FF6B35`
- 关闭面板：灰色 `#9A9A9A`

因此正式图标建议做成**单色剪影**；如果希望保留图标原色，需要同步去掉对应位置的 `colorFilter`。
