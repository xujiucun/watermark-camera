# 位置与天气水印说明

## 数据来源与降级

| 场景 | 位置水印 | 天气段 |
| --- | --- | --- |
| 有网 + 有 key + 有定位权限 | 高德逆地理：`省市区` 或 `详细地址` | 高德实况：`晴 16°C` |
| 高德请求失败 | 回落系统 `Geocoder`；再失败显示「未获取位置」 | 不显示（除非有 15 分钟内的旧缓存） |
| 无 key（`AMAP_WEB_KEY` 为空） | 系统 `Geocoder`；失败显示「未获取位置」 | 不显示 |
| 无网络 | 系统 `Geocoder`（离线命中）或「未获取位置」 | 不显示 / 旧缓存 |
| 配额超限 / 401 / 403 | 同「高德请求失败」 | 不显示 / 旧缓存 |
| 未授予定位权限 | 显示「未获取位置」 | 不显示 |

经纬度单独一行（地点行下方），格式 `36.444471, 115.940715`（6 位小数，非科学计数法），
与地点取自**同一个定位快照**，不会出现地点与坐标错配；没有定位/无权限时整行不显示，不会出现 `0.000000, 0.000000`。
面板中「经纬度」开关默认开启。

缓存策略：地址缓存 30 分钟且移动不超过 300 米时直接复用；天气按 adcode 缓存 15 分钟。
进入拍摄页/回到前台时刷新，拍照过程不发起网络请求，不阻塞快门。

## key 的存放与更换

- 不要硬编码。放在工程根目录 `local.properties`：

```properties
AMAP_WEB_KEY=你的高德Web服务key
```

- Gradle 通过 `buildConfigField("String", "AMAP_WEB_KEY", ...)` 注入，代码里读 `BuildConfig.AMAP_WEB_KEY`。
- `local.properties` 已在 `.gitignore` 中，不会提交。
- 换 key：改 `local.properties` → 重新构建安装即可，不用改代码。
- key 必须是高德开放平台的 **Web 服务** 类型（不是 Android 平台 key），且不要设置 IP 白名单（手机 IP 不固定）。

## 隐私说明

位置与经纬度会发送给高德（`restapi.amap.com`）用于逆地理和天气查询，除此以外不上传任何数据，也没有广告/统计 SDK。
